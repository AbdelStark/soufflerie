# Dataset evidence

[`design-mvp-v1.json`](design-mvp-v1.json) freezes the canonical 1,000-point
maximin design, exact 600/200/200 split membership digest, distribution and
spacing statistics, correlations, and complete lattice/geometry preflight
counts. It is deterministic evidence generated before remote solver execution;
it is not the dataset manifest or evidence that 1,000 solver runs have completed.

Reproduce or verify it with the commands in
[`docs/data/design.md`](../../docs/data/design.md).
