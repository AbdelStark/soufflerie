# Validation status: NOT EVALUATED

Soufflerie does not yet have a canonical three-seed validation report. The
deterministic report schema, renderer, lineage checks, and red-status fixture
are implemented, but the measured release evidence depends on canonical model
training and issue [#31](https://github.com/AbdelStark/soufflerie/issues/31).

The checked fixture is synthetic. This file intentionally contains no generated
metric values and must not be presented as release evidence. Issue #31 will
replace it with output from `reports/validation.json`, including the full plot
manifest and exact report identity.

See [the reporting guide](../docs/validation/reporting.md) for the generation,
lineage, and verification contract.
